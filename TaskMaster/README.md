# TaskMaster

TaskMaster es una aplicación de gestión de tareas desarrollada como proyecto del ciclo DAM.

El proyecto comenzó como una aplicación Java por consola y posteriormente se amplió con una interfaz web sencilla para facilitar la interacción con la aplicación.

Actualmente permite crear, visualizar, editar y eliminar tareas de forma básica.


## Tecnologías utilizadas

- Java
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git y GitHub


## Funcionalidades principales

### Aplicación Java
- Gestión de usuarios
- Creación de tareas
- Cambio de estado de tareas
- Filtrado por categorías
- Visualización de tareas por usuario

### Interfaz web
- Navegación entre páginas
- Listado de tareas
- Formularios de creación y edición
- Eliminación de tareas
- Diseño responsive adaptable a móviles
- Uso de animaciones y Flexbox

# Reto 5 – Desarrollo de la interfaz

En este reto se desarrolló la interfaz web del proyecto TaskMaster.

Se implementaron diferentes vistas HTML con navegación entre páginas, formularios de contacto y visualización de tareas.

También se aplicaron estilos CSS utilizando Flexbox, diseño responsive, efectos hover, animaciones y propiedades de posicionamiento.

La solución fue desarrollada y subida directamente al repositorio GitHub del proyecto.
